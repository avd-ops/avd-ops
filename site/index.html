Open-source toolkit for Azure Virtual Desktop

Azure Virtual Desktop, from inventory to operations, as code you can read.

Read what an AVD environment is, decide what it should be, deploy a hardened landing zone, and run it with agents a person approves. Bicep and PowerShell, run from Azure Cloud Shell.

What they share

  • Read first, change with approvalCollectors and agents read freely. Every change to an estate goes through a plan a person approves, with a kill switch.
  • Tenant data stays with the tenantPublic repos hold generalized knowledge only. Estate data lives in the owner's private repo, and guards in CI catch leaks.
  • Every number traces to evidenceRules carry a history and a reason, sizing comes from measured observations, and answers cite a commit.
  • Azure-native and openBicep, PowerShell and GitHub Actions, all runnable from Azure Cloud Shell.

Contribute

Contributions and forks are welcome and encouraged. Fork a repo and make it your own, or send back what you learn: an issue for a bug, a question or an idea, or a pull request with a fix, a test, a doc or a lesson from a real lab run. Small pull requests are easiest to review.

Before you open one, run the checks the repo's README lists and keep tenant data, IDs and secrets out of the repo, issues and pull requests. A change to a contract between repos comes with the matching pull request in the repo on the other side.
