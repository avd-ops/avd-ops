Optional tier

avd-liquidware

An optional Liquidware tier on top of a landing zone: ProfileUnity, FlexApp through AVD app attach, CommandCTRL, and Stratusphere UX for assessments. FSLogix stays the profile container.

What it does

  • One entry point, Deploy-LiquidwareTier.ps1, built slice by slice and read-only so far.
  • Stratusphere UX in Azure: preflight, the Hub, Database and Collector appliances, Connector ID Key rollout and teardown.
  • Reads the landing zone by its naming convention and never changes its default deployment.
  • Bring your own Liquidware licenses. No binaries or license material live in the repo.

Try it in a lab

# Azure Cloud Shell (PowerShell)
if (-not (Test-Path ~/avd-liquidware)) { git clone https://github.com/nickprignano/avd-liquidware.git ~/avd-liquidware }
Set-Location ~/avd-liquidware; git checkout -q main; git pull -q --ff-only
./scripts/Deploy-LiquidwareTier.ps1 -NamePrefix avdlz -Environment dev -Component ProfileUnity,FlexApp,Stratusphere -Action Check

Full prerequisites and steps are in the README.
