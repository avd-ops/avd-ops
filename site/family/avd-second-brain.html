On top: how it gets smart and self-improving

avd-second-brain

One memory across the AVD lifecycle: what each estate looked like, what broke, what the organization learned, and why each rule is what it is.

Built, growing

What it does

  • A knowledge base of generalized facts: app catalog, rules with their history, sizing calibration and shared runbooks.
  • Estate vaults keep one customer's estate in that customer's own private repo. Tenant data never comes back here.
  • A docs consistency check and a generated handbook keep every repo's docs in step with the code and the contracts.
  • The family knowledge base: topic pages, decision records, known errors and the sources watched to keep it current.
  • Models propose, people approve. Knowledge changes only through a pull request a person merges.

Try it in a lab

# Azure Cloud Shell (PowerShell)
if (-not (Test-Path ~/avd-second-brain)) { git clone https://github.com/avd-ops/avd-second-brain.git ~/avd-second-brain }
Set-Location ~/avd-second-brain; git checkout -q main; git pull -q --ff-only
./scripts/Sync-BrainSources.ps1
./scripts/Find-BrainKnowledge.ps1 'fslogix kerberos'
./scripts/Find-BrainKnowledge.ps1 -Calibration
