avd-current-state

Read-only PowerShell that answers what is in an AVD environment today, and whether a subscription is ready for a deployment and the deployment landed correctly.

What it does

  • The collector builds a portable evidence package of the AVD workload and the platform around it.
  • The validator runs preflight and post-deployment checks and writes a pass/fail report.
  • Only Get- and Test- calls against Azure. Nothing is created, changed or deleted.
  • The facts script turns packages into one redacted snapshot (contract C11): counts, public values and pseudonyms, no names or IDs.

Try it in a lab

# Azure Cloud Shell (PowerShell)
if (-not (Test-Path ~/avd-current-state)) { git clone https://github.com/nickprignano/avd-current-state.git ~/avd-current-state }
Set-Location ~/avd-current-state; git checkout -q main; git pull -q --ff-only
./avd_current_state_collector.ps1
