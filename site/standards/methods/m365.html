Microsoft 365 and collaboration method

methods/m365.md · Edition cfcc302 of avd-assess, 2026-10-27. What changed

How to judge the Microsoft 365 Apps, OneDrive, Teams, and browser multimedia settings that run inside Azure Virtual Desktop sessions. It is the assessment method applied to the Microsoft 365 control plane (m365), linking the images (images) and remote protocol (protocol) pillars to the Intune and tenant policy surfaces that configure them ([G1]).

Method

  1. Ask whether the estate runs Microsoft 365 Apps, OneDrive, and Teams inside AVD sessions (intake.m365PlaneScope) before judging collaboration policies ([G2], [G1]).
  2. Check Microsoft 365 Apps shared computer activation on pooled multi-session hosts so multiple users can activate Microsoft 365 Apps on the same session host without consuming personal activation slots ([1, shared-computer-activation], [2, B01.09], [G1]).
  3. Check OneDrive per-machine installation, Files On-Demand, and Known Folder Move so user folders redirect silently to OneDrive without bloating the FSLogix profile container with full local copies ([1, onedrive-per-machine], [3, files-on-demand-vdi], [3, silent-config-and-kfm], [3, per-machine-install], [G1]).
  4. Check Microsoft Teams media optimization for VDI (SlimCore / WebRTC media redirection and IsWVDEnvironment) so audio, video, and screen sharing offload to the local client endpoint instead of rendering on the session host CPU ([4, media-optimization], [4, classic-teams-end], [2, B01.10], [2, B03.02], [G1]).
  5. Check browser multimedia redirection (MMR) and WebRTC redirection policies where users watch browser video or use web-based calling inside sessions ([5, mmr-browser-video], [2, B03.02], [G1]).
  6. Check update channel and new Outlook readiness so M365 Apps updates follow the servicing model for the host pool rather than fighting image rollouts ([1, line-of-business-after], [6, multisession-image-based], [G1]).
  7. Score M365 checks as not applicable when intake.m365PlaneScope is "not-used", and leave checks unknown when the m365 plane was not collected ([G1], [G3]).

Not yet known

  • How often estates deliver Shared Computer Activation and OneDrive Known Folder Move through the golden image registry or Group Policy instead of Intune settings catalog profiles ([G1]).
