Azure security baseline for Azure Virtual Desktop (Microsoft cloud security benchmark)

references/mcsb-avd-baseline.yaml · Edition a5a7eee of avd-assess, 2026-10-21. What changed

Microsoft Learn. Azure security baseline for Azure Virtual Desktop (Microsoft cloud security benchmark). Pinned at git_commit_id 2ee57af, updated 2026-08-04; read 2026-10-20. Microsoft Learn content (link only). We keep one line in our own words per claim and link the source; its text stays with its publisher. Maps the benchmark's controls to AVD feature by feature (supported, on by default, who configures it). Claim IDs are the benchmark's control IDs, used to group security findings. It covers the AVD service; session hosts also fall under the VM baseline. On 2026-10-20, LT-1's guidance talked about Key Vault alerts, likely an upstream copy error.

Read the source

The Learn pin names the version we read; Microsoft does not publish that commit, so the pin is a record, not a readable copy. The live page may have changed since the read date.
