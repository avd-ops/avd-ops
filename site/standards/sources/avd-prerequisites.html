#rtt-under-150 published

Round-trip time from the client's network to the host pool's Azure region should be under 150 ms; put session hosts in the region closest to users.

✓ mapped○ measurable✓ validated

Cited by Baseline profile: what good looks like, Collection method, Network method, Sample check method, Targets and benchmarks. Observations: extends region-latency-from-the-user. Cite: avd-assess@a5a7eee:references/avd-prerequisites.yaml#rtt-under-150

Users connect with Windows App or the Remote Desktop client; AVD doesn't support the RemoteApp and Desktop Connections or Remote Desktop Connection (MSTSC) clients.

Session hosts run 64-bit Windows 11 or 10 Enterprise (multi-session or single-session) or Windows Server 2016 to 2025; different pools can run different OSes.

Six identity scenarios are supported, from Entra-only users on Entra joined hosts to synced users on hosts joined to AD DS or Entra Domain Services; Entra ID always authenticates the user.
