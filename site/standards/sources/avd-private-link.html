#three-sub-resources published

Private Link for AVD has three sub-resources: connection (one per host pool), feed (one per workspace) and global (initial feed discovery, one for the whole AVD deployment).

✓ mapped○ measurable○ validated

Cited by Network method. Cite: avd-assess@a5a7eee:references/avd-private-link.yaml#three-sub-resources

#four-scenarios published

Four supported layouts run from everything private (global, feed and connection endpoints) through feed and connection only and connection only, to no Private Link at all.

✓ mapped○ measurable✓ validated

Cited by Network method. Observations: agrees private-link-session-hosts-only. Cite: avd-assess@a5a7eee:references/avd-private-link.yaml#four-scenarios

#global-workspace published

The global endpoint belongs on a dedicated workspace with no application groups; deleting that workspace stops feed discovery for every user, and it stays reachable from public routes whatever its access setting.

✓ mapped○ measurable○ validated

Cited by Network method. Cite: avd-assess@a5a7eee:references/avd-private-link.yaml#global-workspace

#public-access-settings published

Workspaces take public access enabled or disabled; host pools also take enabled for clients with session hosts private, which denies a session whenever the session host uses a public route.

✓ mapped○ measurable○ validated

Cited by Network method. Cite: avd-assess@a5a7eee:references/avd-private-link.yaml#public-access-settings

#address-headroom guidance

Private endpoint IP allocations can grow during capacity expansions, so the endpoint subnet needs headroom.

✓ mapped○ measurable○ validated

Cited by Network method. Cite: avd-assess@a5a7eee:references/avd-private-link.yaml#address-headroom

#udp-opt-in published

UDP over Private Link is blocked unless the host pool opts in to the direct UDP path, and the opt-in needs public-network Shortpath (STUN and TURN) turned off.

✓ mapped○ measurable○ validated

Cited by Network method, Remote protocol and session method. Cite: avd-assess@a5a7eee:references/avd-private-link.yaml#udp-opt-in

#client-dns-sequence published

A client resolves the global discovery name, then each workspace feed name and then the host pool gateway name; with Private Link each must answer with the private endpoint address from the client network.

✓ mapped○ measurable○ validated

Cited by Network method. Cite: avd-assess@a5a7eee:references/avd-private-link.yaml#client-dns-sequence

If ports to the connection endpoint are restricted from clients or session hosts, TCP 1-65535 must be allowed, because the endpoint maps ports to the gateway chosen at orchestration.

The Remote Desktop client for Windows on a private network with no internet access can not reach its feed when subscribed to both public and private feeds.
