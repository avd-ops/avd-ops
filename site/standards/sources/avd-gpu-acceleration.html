Enable GPU acceleration for Azure Virtual Desktop

references/avd-gpu-acceleration.yaml · Edition a5a7eee of avd-assess, 2026-10-21. What changed

Microsoft Learn. Enable GPU acceleration for Azure Virtual Desktop. Pinned at git_commit_id 4f40ccf, updated 2025-08-29; read 2026-10-20. Microsoft Learn content (link only). We keep one line in our own words per claim and link the source; its text stays with its publisher. On 2026-10-20 the supported-size table still listed the NVv3 and NVv4 series, which the NV family page says retired on 2026-09-30, and didn't list NVads V710 v5. Read the table together with the current VM size pages before choosing a size.

Read the source

The Learn pin names the version we read; Microsoft does not publish that commit, so the pin is a record, not a readable copy. The live page may have changed since the read date.
