Start here

avd-ops is the front door for a set of open-source repos that take an Azure Virtual Desktop estate from inventory to operations, as Bicep and PowerShell you can read and run from Azure Cloud Shell. These pages explain how the repos fit together. Each repo stays the source of truth for itself, so for anything detailed (parameters, scripts, specs, lessons) follow the link into that repo. Why the docs live here, and how they're kept, is decision 0002.

Everything here is a personal research project: not for production, provided as is, and not affiliated with the author's employer or Microsoft. Use a dedicated lab subscription and tenant.

Before you run anything

  • Use a lab subscription and tenant you can throw away. Every repo assumes it.
  • Run from Azure Cloud Shell (PowerShell). Each repo's quick start is one block you paste there.
  • Expect Azure charges and tear down when you're done. The repos that deploy say how.
  • Never paste a secret into chat, an issue or a pull request. The scripts read secrets with managed identities or prompt for them locally.

Contributing

Fork any repo, open an issue or a pull request. Put a change in the repo that owns it; these pages only link. A page here that is wrong or out of date is a pull request to avd-ops.
