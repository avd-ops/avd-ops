Start here

Open-source Bicep and PowerShell that build, check and run an Azure Virtual Desktop estate, all from Azure Cloud Shell. Try it in a lab you can throw away.

More

avd-ops is the front door for these repos: they take an Azure Virtual Desktop estate from inventory to operations. These pages explain how the repos fit together. Each repo stays the source of truth for itself, so for anything detailed (parameters, scripts, specs, lessons) follow the link into that repo. Why the docs live here, and how they're kept, is decision 0002.

Everything here is a personal research project: not for production, provided as is, and not affiliated with the author's employer or Microsoft. Use a dedicated lab subscription and tenant.

Before you run anything

Use a throwaway lab, run from Cloud Shell, tear down when you're done, and never paste a secret.

More
  • Use a lab subscription and tenant you can throw away. Every repo assumes it.
  • Run from Azure Cloud Shell (PowerShell). Each repo's quick start is one block you paste there; the conventions behind that are in working from Cloud Shell.
  • Expect Azure charges and tear down when you're done. The repos that deploy say how, and sandbox batches is how several paid test runs are approved and run.
  • Never paste a secret into chat, an issue or a pull request. The scripts read secrets with managed identities or prompt for them locally.
