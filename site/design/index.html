Design system

The one look every avd-ops page and portal shares: tokens, type, the shell around each page, and the shared components. Everything below is drawn with the live stylesheets, so switch the theme in the bar to check both.

How it is built and how another repo takes a pinned copy is in docs/design-system.md.

To start a new page or a Claude artifact in this look, copy a starter from templates/: page.html for a repo, artifact.html for an artifact.

Color

Colors exist only as tokens, each with a light and a dark value. Results colors mean a result, never decoration; info marks work in progress.

Shell

Every page opens in the same frame: the brand bar in the shell ink in both themes, with the Docs, Deploy and Assess switcher, the theme button and, below 64rem, the menu button that opens the side list as a drawer. Under the bar, the research notice is one line that opens to the full text. Controls on touch screens are at least 44px.
