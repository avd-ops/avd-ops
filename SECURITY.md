# Security policy

avd-ops is a personal research project, not for production, provided as is, and not affiliated with the author's employer, Liquidware or Microsoft. There is no support agreement and no response time, but reports are welcome and read.

## Reporting a vulnerability

- **Privately, please.** Use **Report a vulnerability** on this repository's Security tab (GitHub private vulnerability reporting). If that button isn't there, open an issue titled "Security contact request" with no details, and a private channel will be arranged.
- **Never put secrets, tenant, subscription or object IDs, names or estate data in a report or an issue.** Issues are public.
- Say what is affected (a page, a script), how it can be misused, and how to reproduce it.

## What is in scope here

This repo is the static site at avd-ops.dev and the scripts that build it; it has no Azure access. A flaw in a repo that runs against Azure belongs to that repo. The [security review page](https://avd-ops.dev/security.html), rendered from avd-assess's security review map, says which repo does what.
