# GitHub Codespaces setup

Personal project, not for production, provided as is; not affiliated with the author's employer or Microsoft.

A dev container for working with the AVD repos in GitHub Codespaces: PowerShell 7, Azure CLI with
Bicep, GitHub CLI, the Az and Graph sign-in modules, Pester and PSScriptAnalyzer, on a 2-core
machine.

Copy the `.devcontainer` folder into a repo you own, such as your fork or your private companion
repo, then create a codespace on that repo. The steps, the free monthly allowance and the settings
that keep it at $0 are in
[Run the AVD repos in GitHub Codespaces](../../docs/knowledge/getting-started/shell-codespaces.md).
